# Smart File Cleaner 🧹

Script en Python para organizar y limpiar carpetas (Descargas, Escritorio, etc.) de manera automática y clasificada.

## 📁 Estructura del Proyecto

```
smart-file-cleaner/
├── .gitignore          # Exclusión de archivos temporales, cachés y datos personales
├── config.py           # Configuración de rutas, extensiones y palabras clave
├── cleaner.py          # Lógica para mover y clasificar los archivos
├── main.py             # Script principal de ejecución
└── README.md           # Documentación del proyecto
```

## 🚀 Uso Rápido

```bash
python main.py
```
